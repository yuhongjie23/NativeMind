## 0. 这次只做什么

本次生产范围：

```text
空间：图书馆 library
天气：晴天 clear
时间：先 day，母版通过后再派生 dusk / night
平台：Windows Tauri 桌面端
画面：全屏 16:9
角色：学习女孩 + 小芽团宠物
目标：安静、可爱但成人可用、低打扰、可长期停留
```

本次不做：

- 雨丝、玻璃水滴、雪花和积雪。
- 书房版本。
- 手机端构图。
- 完整房间长视频。
- 烘焙了女孩、宠物和 HUD 的不可拆背景视频。
- 带文字的 AI UI。
- Agent 自由控制资源文件名。

“晴天版本”仍然包含三个时间阶段：

```text
library + clear + day
library + clear + dusk
library + clear + night
```

但生产顺序必须是：

```text
day 空景母版通过
  -> day 分层资产
  -> dusk 静态变体
  -> night 静态变体
  -> 女孩角色与动作
  -> 宠物角色与动作
  -> 晴日环境微动画
```

不要并行从零生成 day、dusk、night 三张完全独立的图书馆。

## 1. 当前项目真实接线状态

### 1.1 已经明确的场景状态轴

当前类型：

```text
SceneId:     study-room | library
TimePhase:   day | dusk | night
WeatherType: clear | rain | snow
FocusState:  idle | active | paused | elapsed
```

这些轴独立组合。不要创建单独的 `library-clear-day-page.tsx`。

### 1.2 图书馆现有锚点

当前 `scene-manifest.ts`：

```yaml
girl:
  x: 0.46
  y: 0.80
  scale: 1
pet:
  x: 0.65
  y: 0.63
  scale: 1
focusHud:
  x: 0.87
  y: 0.45
  scale: 1
dock:
  x: 0.50
  y: 0.06
  scale: 1
speechBubble:
  x: 0.68
  y: 0.52
  scale: 1
```

说明：Manifest 的锚点是布局合同。即梦生成的背景不能把关键书架、高亮窗格或复杂道具放进这些位置的 UI 可读区。

### 1.3 当前 CSS 图书馆构图

当前 fallback 大致采用：

```text
左侧 3.5%-15%：高书架
左侧 17.5%-25.5%：较远书架
中右侧 52%-76%：高窗
长桌：x 9%-91%，桌面约 y 65%
女孩：中心约 x 46%，基线约 y 80%
宠物：中心约 x 65%，基线约 y 63%，接近桌面
Focus HUD：右侧约 x 87%，中心 y 45%
Dock：底部中央
Lofi HUD：右下角
```

正式图书馆母版应保留这套“左书架、中部学习、右中高窗、最右 HUD”的空间逻辑。可以优化美术比例，但不要把窗口移到最右侧挡住 Focus HUD，也不要把女孩移到画面边缘。

### 1.4 哪些资源已经可直接接入

| 资源 | 当前状态 | 生成后的处理 |
| --- | --- | --- |
| 宠物 Sprite Sheet | `SpriteRenderer`、Manifest、reduced-motion 已实现 | 可最先试接 |
| 宠物 CSS fallback | 已实现 | 正式资源失败时保留 |
| 图书馆背景路径 | Manifest 已声明 day/dusk/night | `SceneBackground` 尚未读取正式图片，后续需接线 |
| Window mask 路径 | Manifest 已声明 | `WindowMaskedLayer` 当前仍按 CSS 几何区域，需要后续接图片 mask |
| 女孩动作类型 | 已有 `GirlAction` 和统一 Renderer | Asset Resolver 当前没有女孩正式资源映射，后续需接线 |
| Video Renderer | 已能播放 `<video>` | 可用于女孩透明 WebM，但需要 Resolver 描述 |
| Lottie / Rive | 仍主要是类型预留 | 本批不依赖 |
| 晴日环境微动画 | 尚无独立 Ambient Resolver | 可以先生产，后续再接入 |

结论：

> 资产可以先按最终合同生产，但接入优先级应是宠物 Sprite -> 背景静态图 -> 女孩 writing-loop -> 其他动画。

## 2. 不要先生成“最终成片”

即梦工作流最容易失败的方式是：

```text
一句超长提示词
  -> 同时要求图书馆、女孩、宠物、白天、动画、UI、天气
  -> 得到一段好看的完整视频
  -> 无法切换时间、角色状态、宠物状态和面板
```

正确方式：

```text
Style DNA
  -> Library Scene DNA
  -> 白天晴天空景母版
  -> 构图安全区验证
  -> 从母版拆静态层
  -> 从母版派生 dusk / night
  -> 独立生成环境循环
  -> 独立生成女孩透明动画
  -> 独立生成宠物 Sprite Sheet
  -> 在前端组合
```

每一轮只允许一个主要变量：

| 轮次 | 锁定 | 唯一变化 |
| --- | --- | --- |
| 风格探针 | 主体和构图简化 | 风格候选 |
| 空景母版 | Style DNA | 图书馆空间结构 |
| 母版修正 | 风格和空间 | 一个明确失败点 |
| 黄昏 | 空间、镜头、家具 | 光照时间 |
| 夜晚 | 空间、镜头、家具 | 光照时间 |
| 云循环 | 其他全部为空 | 云的水平运动 |
| 女孩 writing | 角色、相机、座位 | 手腕书写 |
| 宠物 idle | 宠物 DNA、画布 | 呼吸和眨眼 |

## 4. 生产总顺序与门禁

### 批次 A：风格和空间

```text
A0 建立素材记录表
A1 提取或定义 Style DNA
A2 生成 4 张低成本风格探针
A3 只选择 1 个方向并冻结
A4 生成图书馆 day + clear 空景候选
A5 修正构图，冻结母版
```

门禁 A：

- 图书馆不是宏伟大厅、魔法学院或儿童绘本教室。
- 女孩、宠物、Focus HUD、Dock 安全区成立。
- 相机和透视可以长期固定。
- 没有可读书名和 AI 文字。
- 第一眼是“安静学习空间”，不是“书架展示图”。

### 批次 B：静态分层

```text
B1 从母版清理出 background plate
B2 从同一母版提取 table foreground
B3 提取可选前景书架/桌角
B4 手工或图像编辑生成 window mask
B5 在前端设计稿中试叠女孩/宠物占位框
```

门禁 B：

- 所有层叠加后与母版一致。
- 前景桌面可以正确遮住女孩下半身。
- Window mask 精确覆盖玻璃，不覆盖木框。
- 分层边缘没有白边或色污染。

### 批次 C：时间变体

```text
C1 day 母版作为唯一结构参考
C2 生成 dusk
C3 生成 night
C4 三张交叉淡入检查
```

门禁 C：

- 家具、书本、窗框位置逐像素近似稳定。
- 只改变天空、窗光、室内反射、阴影和灯光。
- 夜晚不是纯蓝滤镜，黄昏不是纯橙滤镜。

### 批次 D：角色

```text
D1 冻结女孩 Character DNA
D2 生成图书馆坐姿关键帧
D3 将关键帧融合到母版验证比例和光线
D4 生成 writing-loop
D5 生成宠物 Sprite Sheet
D6 接入 poster / Sprite 做首轮验证
```

门禁 D：

- 女孩手与纸、椅子、桌面关系正确。
- 透明角色放进图书馆不显得像贴纸。
- 宠物不遮挡女孩和 Focus HUD。
- writing 和 pet idle 可同时循环而不抢注意力。

### 批次 E：环境与扩展动作

```text
E1 云循环
E2 飞鸟循环
E3 光束尘埃
E4 女孩 turn-page
E5 女孩 stretch 三段
E6 女孩 drink / look-outside
E7 宠物睡眠和交互动作验收
```

## 5. 参考图准备方式

### 5.1 每张参考图只能有主要职责

| 参考图 | 责任 | 不能决定 |
| --- | --- | --- |
| STYLE-A | 色彩范围、笔触、轮廓、材质 | 图书馆家具布局 |
| SPACE-A | 图书馆布局、透视、窗户和长桌 | 女孩脸和衣服 |
| LIGHT-A | 晴日光向、软硬、色温 | 角色身份 |
| GIRL-A | 女孩脸、发型和比例 | 图书馆空间 |
| OUTFIT-A | 服装结构和颜色 | 女孩脸型 |
| POSE-A | 坐姿、写字接触关系 | 风格和色板 |
| PET-A | 宠物身份与比例 | 场景构图 |

不要上传五张“都很好看但职责冲突”的参考图。

### 5.2 参考优先级

```text
角色身份参考 > 场景结构参考 > 构图安全区 > 风格参考 > 动作参考 > 氛围参考
```

如果风格参考要求超宽落地窗，而场景结构参考要求高窗，必须明确：高窗结构优先，风格图只负责笔触和光色。

### 5.3 即梦每轮记录

```yaml
generation_id:
date:
model_name:
model_version:
mode: text-to-image / image-to-image / image-to-video / start-end-frame
prompt_version:
references:
  - file:
    responsibility:
strength_or_similarity:
seed_if_available:
aspect_ratio:
duration:
resolution:
accepted: false
reject_reason:
output_files:
```

不要把即梦历史记录当正式资产库。正式资产、提示词和参考图都要复制到项目外的受控素材目录并版本化。

## 6. 晴天图书馆 Style DNA

以下是本批次的默认风格。若用户后续提供参考图，应先运行第 9.1 节的 Style DNA 提取提示词，再替换这里的值。

### 6.1 必须保持

```yaml
style_id: nativemind-library-clear-v01
medium: 2D 柔和扁平插画 + 极轻纸张颗粒
audience: 成人学习者
mood:
  - 安静
  - 温和
  - 沉静
  - 包裹感
  - 晴日可感但室内偏暗
  - 有生活感
  - 低打扰
color_range:
  aged_paper: "#D8CFBD"
  parchment_shadow: "#B9AA92"
  walnut: "#725240"
  deep_walnut: "#49372F"
  olive_gray: "#626D64"
  charcoal_green: "#303A35"
  dusty_blue: "#71828A"
  antique_brass: "#A88652"
  text_safe_dark: "#222A27"
color_area:
  wood_and_deep_neutrals: "45%-55%"
  olive_and_charcoal_gray: "20%-25%"
  aged_paper_and_muted_taupe: "10%-15%"
  dusty_blue: "5%-10%"
  brass_highlight: "小于 5%"
line:
  - 细而柔和的深暖灰或深绿灰轮廓
  - 不使用纯黑粗描边
shape:
  - 家具边缘清楚但不过分卡通
  - 形状圆润克制
material:
  - 哑光木材
  - 轻微纸张颗粒
  - 低反光玻璃
lighting:
  - 主光从中右高窗向左下方进入
  - 室内整体为中低明度，以柔和间接日光为主
  - 晴天只通过窗外天空和桌面局部落光表达，不提高整屋曝光
  - 窗户是受控的小面积亮部，不得过曝成白色光洞
  - 阴影具有深胡桃木和橄榄绿灰层次，暗部保留书架细节
  - 高光面积小于画面 10%，旧纸色只用于纸张和少量受光面
  - 不使用舞台光和强体积光
background_complexity:
  - 左侧书架中等细节
  - 中部学习区清晰
  - 右侧 HUD 区低细节低对比
camera:
  - 固定平视略高 3-5 度
  - 中远景
  - 标准焦段感，约 40-50mm
  - 无广角畸变
```

### 6.2 可以变化

- 少量书脊颜色排列。
- 一两件低对比桌面小物。
- 窗外云的位置。
- 极少量飞鸟的位置。
- 阳光在桌面的柔和明暗分布。

### 6.3 禁止变化

- 书架、窗户、长桌和座位的大结构。
- 女孩和宠物锚点。
- Focus HUD 安全区。
- 镜头、地平线和透视。
- 风格媒介。
- 木材色相和轮廓风格。
- 书本是否出现可读文字。

## 7. 图书馆 Scene DNA

### 7.1 固定空间结构

```yaml
scene_id: library-clear-v01
canvas: 2560x1440
camera:
  position: 固定在学习桌正前方略偏左，平视略高
  viewer_relation: 屏幕前用户是正面观察者，不是第一人称手部 POV
  optical_axis: 指向中部学习座位，不指向窗户
  vanishing_point: [0.48, 0.44]
  lens_feel: 40-50mm 标准镜头
  table_front_edge: 与画面底边近似平行，倾斜不超过 5 度
  movement: none
architecture:
  left_bookshelf:
    x: 0.035-0.15
    y: 0.06-0.86
  rear_bookshelf:
    x: 0.175-0.255
    y: 0.08-0.80
  high_window:
    x: 0.52-0.76
    y: 0.06-0.56
  long_table:
    x: 0.09-0.91
    top_y: 0.65
anchors:
  girl: [0.46, 0.80]
  pet: [0.65, 0.63]
  focus_hud: [0.87, 0.45]
  speech_bubble: [0.68, 0.52]
safe_areas:
  top_hud: [0.02, 0.02, 0.96, 0.09]
  focus_hud: [0.77, 0.18, 0.20, 0.62]
  bottom_dock: [0.28, 0.87, 0.44, 0.11]
  lofi_hud: [0.78, 0.87, 0.20, 0.10]
crop_allowance:
  left: 0.08
  right: 0.08
  top: 0.06
  bottom: 0.10
```

### 7.2 视觉焦点顺序

```text
1. 中部偏左的学习座位和女孩活动区
2. 面向用户展开的桌面、座位与前后景层次
3. 右侧 Focus HUD
4. 中右高窗的晴日自然光
5. 左侧书架的空间深度与宠物
6. Dock 与音乐条
```

空景阶段没有女孩，但要用“空椅子 + 打开的笔记本 + 光线落点”暗示学习活动区。

### 7.3 道具预算

保留：

- 一本打开的笔记本。
- 一支铅笔。
- 一盏小型阅读灯。
- 一小叠 2-3 本无文字书。
- 一个简单书签或纸页边缘。
- 可选一只无品牌水杯。

不要同时加入：地球仪、打字机、留声机、雕像、烛台、猫、花束、相框、复杂钟表和大量文具。它们会让 AI 把图书馆做成装饰橱窗。

## 8. 提示词组合规则

即梦正式提示词按三块组合：

```text
全局母提示词
+ 当前资产专项提示词
+ 通用负面约束
```

如果模型对超长提示词执行变差，按以下优先级删减：

```text
先删除重复形容词
再删除不影响当前资产的其他动作说明
保留角色身份、空间结构、镜头、光线、安全区和禁止项
```

### 8.1 全局母提示词

```text
为 Windows 桌面端学习辅助软件 NativeMind 制作同一视觉系列的可替换美术资产。
```

## 10. 批次 B：静态分层提示词

### 10.1 分层原则

不要让即梦分别从零生成背景和桌面。正确做法是：

## 12. 批次 E：晴日环境微动画提示词

本章为了紧接场景时间变体而提前集中说明环境层；实际生产顺序仍按第 4 节执行：先完成批次 D 的女孩与宠物基准，再制作本批次的环境微动画和扩展动作。

### 12.1 总原则

晴天不是“什么都不动”，但只能有低频环境运动：

```text
慢云
极少量远鸟
极轻尘埃
可选书页边缘微动
```

不要让阳光强度持续呼吸，不要让整个背景推拉，不要让书架和桌面抖动。

### 12.2 窗外慢云循环

推荐模式：使用窗外区域裁切图作为结构参考，单图图生视频。

```text
输入 NativeMind 图书馆 day + clear 母版的高窗玻璃区域参考。

任务：生成独立的晴天薄云循环层，只表现窗外天空中的一到两层低饱和薄云以极慢速度从右向左水平移动。

固定相机，无推拉、无摇移、无变焦。云形柔和、透明度低、速度稳定，不能遮满天空，不能改变天空整体亮度。远山或树冠完全静止。8-12 秒无缝循环，首尾云量、位置趋势、曝光和颜色连续。

不生成窗框、室内、桌面、人物、宠物、鸟、文字、阳光闪烁和天气变化。输出透明 alpha；若即梦无法稳定输出 alpha，使用与天空颜色差异明确但不污染边缘的可抠像底，并在后期去底。
```

输出建议：

```text
1920×1080 或与场景同画布
24fps
8-12s
VP9 WebM alpha 或 PNG/WebP sequence
window mask 内播放
```

### 12.3 远处飞鸟循环

```text
任务：生成 NativeMind 晴天图书馆窗外的独立远鸟动画层。

画面只有 2-3 只非常小、低对比、简化轮廓的远处飞鸟，从窗外画面左侧缓慢飞向右侧。飞行高度和速度稳定，翅膀动作简洁，鸟之间保持距离。固定相机，背景透明，6-10 秒循环或一次性经过后长时间停用。

飞鸟不能靠近镜头，不能成为主角，不能出现大群鸟、羽毛细节、突然转向、镜头跟随和强黑色轮廓。不要生成天空、窗框、房间、文字和其他动物。
```

建议：飞鸟更适合作为低频一次性 ambient cue，而不是永远循环。

### 12.4 光束尘埃循环

```text
输入图书馆 day 母版，参考高窗光线方向。

任务：生成独立、极低对比的晴日空气尘埃层。少量极小颗粒只在高窗射入的柔和亮区中缓慢漂浮，运动方向不完全一致但速度非常慢，颗粒数量稀疏，透明度低。

固定相机，10-15 秒无缝循环，首尾密度和亮度连续。不要生成明显光柱、闪粉、亮斑、镜头灰尘、bokeh 圆球、魔法粒子和全屏覆盖。背景透明，不改变底图曝光。
```

### 12.5 书页边缘微动

P3 可选，只有实际效果自然时保留。

```text
输入固定桌面上一本打开书的关键帧。生成 3-4 秒无缝循环：只有右侧一小片纸页边缘受非常轻的室内空气影响抬起 1-2mm 后回落，书本位置、页码、纸张数量和阴影完全稳定。

固定相机、透明背景，不自动翻页，不生成文字，不改变书本厚度和颜色。若纸页结构出现变形，放弃该动画，保留静态书本。
```

```text
输入 writing-loop 标准姿势作为起点，另提供翻页完成后与原书写姿势相容的终点关键帧。

生成 2-3 秒一次性 turn-page：女孩停笔，右手将铅笔稳定放在笔记本右侧，左手捏住右侧单张纸页边缘，缓慢将一页翻向左侧并轻轻压平，然后右手重新拿起同一支铅笔，回到可接 writing-loop 的姿势。

只翻一页。笔记本尺寸、位置和厚度稳定；手、纸页和铅笔接触清楚。固定相机、透明背景、统一锚点。禁止多页乱飞、书本变形、铅笔消失、换手和文字出现。
```

### 13.8 Stretch 三段提示词

复杂动作分三次生成，不要求一条视频完成全部过程。

#### Stretch Enter

```text
从 writing-loop 标准姿势开始，生成 0.8-1.2 秒 stretch-enter：女孩停止书写，将铅笔稳定放在笔记本右侧，双手离开纸面，身体从轻微前倾缓慢坐直。终点是自然坐直、双手准备抬起的姿势。固定相机和锚点，透明背景。
```

#### Stretch Main

```text
从已通过的坐直姿势开始，生成 2-3 秒 stretch-main：女孩双臂以克制幅度向上伸展，肩颈放松，轻轻呼气，表情保持自然疲惫而非表演。双手、手臂和头发结构稳定，不离开画布，不改变椅子和笔记本。
```

#### Stretch Exit

```text
从 stretch-main 终点开始，生成 0.8-1.2 秒 stretch-exit：双臂缓慢放下，身体恢复轻微前倾，右手拿回同一支铅笔，左手回到同一页，最终姿势与 writing-loop 首帧一致。固定相机、透明背景，保证手和道具接触清楚。
```

### 13.9 Drink 提示词

只有母版中确定保留水杯时制作。

```text
从 writing-loop 标准姿势开始，生成 2.5-3.5 秒一次性 drink：女孩停笔，将铅笔放在笔记本右侧，用右手拿起桌面同一只无品牌水杯，缓慢喝一小口，放回完全相同的位置，再拿起铅笔回到 writing-loop。

水杯形状、颜色、尺寸和液面稳定，手与杯接触清楚。固定相机、透明背景。禁止杯子变化、液体泼洒、夸张仰头、换手和新增吸管。
```

如果杯子接触反复失败，删除该动作，不要为了功能数量接受低质量资产。

### 13.10 Look Outside 提示词

```text
从 idle 或 writing 标准姿势开始，生成 2.5-3.5 秒一次性 look-outside：女孩停下手腕动作，头部和视线以很小幅度转向中右高窗，停顿约 1 秒，然后自然回到笔记本。身体和椅子位置不变，手仍稳定停在纸面附近。

转头不超过约 20 度，不看镜头，不移动椅子，不站起，不生成窗户和背景。固定透明画布和锚点。
```

## 15. Poster 与 reduced-motion 提示词

每个循环或关键状态都需要静态 poster。Poster 不应简单截取一个模糊中间帧。

### 15.1 女孩 Writing Poster

```text
输入已通过的 writing-loop 和女孩设定图。选择或重绘一张最稳定的中性书写姿势：右手铅笔接触纸面、左手压住书页、眼睛自然睁开、身体轻微前倾、头发和袖口完整。保持透明背景、统一画布、锚点和图书馆晴日光向。不生成运动模糊。
```

### 15.2 女孩 Idle Poster

```text
生成稳定坐姿静态帧：女孩暂时停笔但仍保持学习状态，双手自然停在笔记本附近，眼睛睁开，表情平静。透明背景、无运动模糊、无中间过渡姿势。
```

### 15.3 宠物静态帧

按 `pet-manifest.json` 为每个状态指定最清楚的 `reducedMotionFrame`：

- idle：中性睁眼。
- study：笔记本打开且手稳定。
- needs_input：抬头、芽叶轻举。
- ready：轻微弯眼、已经落地。
- concerned：芽叶稍垂但不哭泣。
- sleep：稳定趴姿。

## 19. 验收与返工

### 19.1 空景 100 分表

| 项目 | 分值 | 判断 |
| --- | ---: | --- |
| Style DNA | 15 | 色板、轮廓、材质、颗粒统一 |
| 空间结构 | 20 | 书架、窗、长桌和座位符合 Scene DNA |
| UI 安全区 | 20 | Top/Focus/Dock/Lofi 区域低细节可读 |
| 光线逻辑 | 15 | 高窗主光明确，阴影柔和且保留细节 |
| 成人可用 | 10 | 不像儿童游戏和营销插画 |
| 长期停留 | 10 | 不刺眼、不拥挤、无高频视觉焦点 |
| 技术质量 | 10 | 分辨率、边缘、无文字、可分层 |

低于 85 分不进入分层阶段。

### 19.2 一票否决

- 高窗、长桌或书架结构在变体中改变。
- Focus HUD 安全区被高对比窗框、灯或书架占据。
- 出现可读或伪造书名。
- 出现随机人物和宠物。
- 图书馆像魔法学院、宫殿、酒店或恐怖场景。
- 角色手与笔、书、杯严重融合。
- 动画相机发生推拉、摇移或缩放。
- 透明边缘有明显白边或背景色污染。
- writing-loop 首尾跳变。
- 宠物动作在专注中持续抢注意力。

### 19.3 返工决策

```text
风格不对
  -> 回 Style Probe，不继续做角色

构图不对
  -> 回 day 空景母版，不生成 dusk/night

家具漂移
  -> 用 day 母版做低变化图生图，不从文本重做

分层边缘错误
  -> 回图像编辑和 matting，不靠调色遮盖

女孩像贴纸
  -> 修正环境边缘色、光向、尺度和遮挡关系

手部失败
  -> 降低动作复杂度或拆成 Enter/Main/Exit

循环失败
  -> 重做关键帧和首尾，不使用长叠化硬掩盖

宠物太吵
  -> 降低位移、FPS、触发频率和气泡策略
```

## 20. 第一轮实际执行清单

用户现在不要一次生成所有资源。第一轮只做以下内容：

### 第 1 天：风格与母版

1. 准备 3-5 张参考图并标注职责。
2. 使用第 9.1 节提取 Style DNA。
3. 使用第 9.2 节生成四张风格探针。
4. 冻结一个方向为 `style-dna-v01`。
5. 使用第 9.3 节生成 4-8 张图书馆白天晴天空景候选。
6. 只选构图，不急着选“细节最漂亮”的一张。
7. 使用第 9.4 节一次只修一个问题。
8. 用真实 HUD 占位图验证 1280×720、1440×900、1920×1080。
9. 冻结 `library-clear-day-master-v01`。

### 第一轮完成标准

只要以下六项全部成立，第一轮就完成：

- 图书馆空间风格满意。
- 书架、长桌和高窗位置固定。
- 女孩活动区自然。
- 宠物锚点可用。
- 右侧 Focus HUD 可读。
- 底部 Dock 和音乐条不压住关键物体。

第一轮不要做：

- 女孩完整动画。
- 宠物全部动作。
- 黄昏和夜晚。
- 雨雪。
- 音频。

母版不稳时，后续每一个资源都会跟着返工。

## 22. 最终原则

```text
先有稳定空景，再有人物。
先有白天母版，再有时间变体。
先有角色关键帧，再有视频。
先验证一个循环，再批量生成动作。
背景、女孩、宠物、天气和 UI 永远分层。
Agent 永远只表达语义，不接触资源路径。
```

晴天图书馆的第一目标不是“做出最多动画”，而是建立一个可以作为后续五组场景共同质量基准的母版。只要空间、风格、光线和安全区稳定，雨天、雪天、书房和 Agent 联动都会明显容易。
