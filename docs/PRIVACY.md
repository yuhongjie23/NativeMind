# NativeMind privacy information

Updated: 2026-11-11. Applies to NativeMind 2.0.1 and the NativeMind Local Anna edition. Cloud organization features below apply only to the regular desktop edition; Anna Local keeps them disabled.

Standard-note organization is explicitly started for one saved note and requires the same separate DeepSeek organization opt-in. It sends the complete body (up to 12,000 characters); longer notes are blocked rather than silently truncated. The preview shows the organized draft, evidence excerpts and the original text. Confirmation saves a separate note and its local search-index job; the original is not overwritten. No further DeepSeek linking or card extraction is automatically triggered by this save. The preview/proposal and evidence remain in local storage. This feature is unavailable in browser demo and Anna Local modes.

Topic composition is started explicitly by selecting 2–8 notes or cards. It sends their titles and up to the first 1,500 characters per note to DeepSeek, subject to the knowledge organization opt-in described below. Topic pages preserve confirmed source references and quotations locally; creating or deleting a topic page does not modify its source notes.

AI title suggestions are started explicitly for one note, with the same separate knowledge-organization opt-in and DeepSeek requirement. Only the first 6,000 characters of that note's body are sent; linked websites are not fetched. The suggested title and a supporting source quote are shown before confirmation. Approving a title updates the local note and unambiguous inline links together; original files and source addresses are preserved. Without substantive source content, a title is not invented. Graphs and incoming/outgoing reference views read saved local records without model requests.

Tasks, notes, imported documents, conversations, learning progress, reviews and settings are stored on your computer. NativeMind does not provide a cloud synchronization service. Backups and exports are saved to the location you choose. A folder you place inside a third-party sync service is subject to that service's own behavior.

Local AI features send requests to Ollama on your computer. Models are installed separately. The regular GitHub desktop edition also offers optional DeepSeek and external search: enabling and using them sends the relevant request/context or search keywords to the selected external service. API keys are stored in local settings; protect your local data and backups accordingly.

AI knowledge organization (link suggestions and knowledge card extraction) has a separate, default-off setting and requires a DeepSeek API key. Enabling it allows imported notes to trigger link suggestions automatically. Relevant excerpts from the current note and candidate notes are sent to DeepSeek and may incur API charges. Card extraction is started explicitly from a note and sends one section at a time, up to 12,000 characters including a short context excerpt from the previous section. The interface discloses the range; subsequent sections require another click. Suggested links and selected cards require confirmation before being saved. Confirmed section progress is stored locally so organization can resume after restarting. Cards retain source quotes and location snapshots locally, including after the original note is deleted. Disabling the setting stops new organization requests; it does not retract requests already sent. This feature does not fall back to a local generation model and is unavailable in the Anna Local edition. Manual links and local search remain available.

The **NativeMind Local edition distributed through Anna disables remote AI and external search**. Its Anna page sends only an empty-argument request to open the local app; the tool returns a fixed launch status. Learning content, local paths, model responses and database access are not exposed through this launch tool. The local user confirms opening the app. Anna processes account, installation and launch metadata under Anna's own policies.

The Anna Local edition uses a separate application data directory from the regular desktop edition. Isolation is based on the Windows user and local application directory; switching Anna accounts under the same Windows user does not create separate learning databases. Software already authorized to read files under that Windows account remains subject to its own permissions.

You can export or restore your learning data using Settings. Uninstalling software does not necessarily erase your learning database or exported backups. Review your chosen data and backup locations before deleting anything. System reminders may display the reminder text through Windows notifications when you enable that feature.

Questions and issue reports: [NativeMind issues](https://github.com/yuhongjie23/NativeMind/issues). Do not include private notes, credentials or complete personal database backups in public reports.
