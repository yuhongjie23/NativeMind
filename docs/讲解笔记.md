# 如何向别人介绍 NativeMind —— 讲解笔记

> 目标：让一个没听说过的人 **5 分钟内理解它是什么、为什么值得用、怎么用**。
> 本笔记按「一句话 → 三个场景 → 三个演示 → 回答常见疑问」组织，可作讲稿或聊天话术。

---

## 一、一句话介绍（开场）

> **NativeMind 是一个"本地优先"的 AI 学习教练——它不替你学习，而是帮你把学习这件事变得有条理：计划、专注、沉淀、复盘，全程数据留在你自己电脑上。**

关键点：**它不是聊天机器人**。市面上 AI 产品都是「你问它答」，NativeMind 是「它帮你把学习过程管理起来」。

---

## 二、为什么值得用？（三个痛点 → 三个答案）

### 痛点 1：「我总在学，但说不清自己学了什么」
**答案：知识自动沉淀**
- 导入 PDF / EPUB / Markdown / 粘贴文本 → 自动建立本地知识库
- 新笔记进来，AI 自动判断它和旧笔记的关系（同一概念？前置？延伸？），一键确认后形成**知识图谱**
- 下次想不起来「当时学过什么」，本地检索几秒出结果

### 痛点 2：「计划做了，专注不了，也复盘不了」
**答案：学习节奏闭环**
- 今天面板：输入一个目标，AI 帮你拆成今天能做的任务
- 专注模式：番茄钟 + 场景环境音，记录真实专注时长
- 复盘：日 / 周 / 月自动生成（昨天没复盘？启动时自动补）——用真实数据说话，不空洞打鸡血

### 痛点 3：「怕数据被 AI 公司拿走，也怕换电脑丢数据」
**答案：数据 100% 在自己手里**
- 所有笔记、任务、复盘存本地 SQLite，**默认不联网**
- AI 用本地模型（Ollama）跑；想要更强可配 DeepSeek key，**自己决定**要不要让数据上云
- 一键导出/恢复，换电脑 5 分钟迁移

## 三、三个演示（现场 5 分钟）

### 演示 1：导入笔记 → 自动关联 → 图谱（2 分钟）
```
1. 打开「知识」面板 → 快速导入 → 粘贴一篇笔记（或选 PDF）
2. 等 3-5 秒 → 弹出「AI 发现 N 条知识关联」确认框
3. 点确认 → 打开「知识图谱」tab → 看到节点和连线
4. 点一个节点 → 右侧显示正文 + 已有关联，可删可加
```
> 讲解词：「注意，所有 AI 建议都要你点确认才生效——它只是助手，不是替你决定。」

### 演示 2：目标拆解 + 专注 + 复盘（2 分钟）
```
1. 今天面板 → 输入「学完深度学习的注意力机制」→ 回车 → AI 拆成 3-5 个小任务
2. 点一个任务 → 开始专注 → 番茄钟走动，切个场景音乐
3. 完成 → 复盘面板 → 生成今日复盘 → 看到它引用了今天的数据
```
> 讲解词：「这是我最喜欢的一点：复盘不是 AI 瞎编，它真的看着你的任务和专注记录说话。」

### 演示 3：数据所有权（1 分钟）
```
1. 设置 → 模型：显示本地 Ollama 状态；可选填 DeepSeek key
2. 设置 → 数据备份与恢复 → 导出 → 生成一个自包含目录
3. 设置 → 搜索：默认 Bing 无 key 可用；选 Google 填 key 走官方 API
```
> 讲解词：「你看，连'用哪个 AI'、'搜哪个引擎'、'数据放哪'都是你控制的——这跟那些打包好的 SaaS 完全不一样。」

## 四、回答常见疑问（Q&A）

**Q1：这和 Notion / Obsidian / 各类 AI 笔记有什么区别？**
> 核心区别是「学习」而不是「笔记」。Notion 是数据库，Obsidian 是双向链接，NativeMind 是**学习闭环**：计划 → 专注 → 沉淀 → 复盘，四件事一体。别的工具要你自己拼装，这里开箱即用。

**Q2：没有好电脑能用吗？**
> 能。不装模型也能跑（AI 降级为模板）；装 Ollama 后 1.5B 小模型 4GB 显存就够；不想跑本地模型，配 DeepSeek key 直接云端。

**Q3：数据真的安全吗？**
> 默认全部在本机 SQLite，不联网。AI 调用只在你自己电脑上跑（Ollama）；只有你**主动**配了 DeepSeek / Google API key，相关请求才出本机，且设置页有明确提示。

**Q4：适合谁？**
> 学生、自学者、程序员、任何「想认真学点东西」的人。尤其适合：觉得「学了很多但没沉淀」、想养成专注习惯、不想被 AI 公司拿走笔记数据的人。

**Q5：开源吗？**
> 是的，MIT 协议，代码在 GitHub（yuhongjie23/NativeMind），可以自己改、自己部署、自己审计。

## 六、讲解小技巧

1. **先问痛点**：开场先问「你最近有没有'学了但感觉没沉淀'的感觉？」——有共鸣再介绍
2. **演示 > 口播**：能现场演示就演示，数据/图谱/复盘的直观感远胜描述
3. **强调"确认门"**：所有 AI 建议要你确认，这是它和"AI 替你乱写"产品的关键差异
4. **留一个钩子**：结束时提一句「换电脑数据 5 分钟迁移」或「复盘自动补」，让他自己想继续了解
5. **截图辅助**：用 `docs/screenshots/` 里的 7 张图（今日/主场景/知识检索/专注/陪伴/写信）配合讲解
