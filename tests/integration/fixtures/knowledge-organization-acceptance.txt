# NativeMind 知识整理验收材料（合成数据）

本材料仅包含算法学习笔记与合成练习，不含个人数据。

## 基础概念

二分查找也称折半查找（binary search）。在本材料的数组查找场景中，前提是数组按升序排列，并支持按下标访问。每次比较中间元素后排除一半候选区间；不能把这种排除规则直接套用到无序数组。

左闭右开区间 [left, right) 包含 left，不包含 right。空区间的条件是 left == right。这里的 lower_bound 问题寻找第一个大于等于目标值的位置，允许结果等于数组长度；它与判断目标值是否存在是两个不同的问题。

当输入数组是 [8, 1, 6, 3] 时，数字 8 实际存在。若错误地按升序二分规则寻找 8，可能根据中间值排除左半区，从而错过 8。这是缺少有序条件导致错误的例子，不是二分查找在有序数组上的反例。

资料没有说明红黑树删除算法，也没有讨论并发哈希表的实现。

## 练习 001：有序输入与结果含义

本题的升序数组是 [3, 5, 8, 12, 16]，下标从 0 开始。查找目标 8 时，该值位于下标 2。这里可以使用二分查找，是因为输入有序，而不是因为数组恰好只有五个元素。

若目标换成 7，该数不在数组中。它大于下标 1 的值 5，小于下标 2 的值 8。第一个大于等于 7 的元素因此位于下标 2。返回插入位置 2 不代表目标已存在，仍需检查该位置的值是否等于目标。

复盘本题时，要分清三个问题：输入满足什么条件、算法返回的是位置还是存在性、区间端点是否包含。说明理由应依据本题数组，不能仅从返回值 2 推断已经找到目标。

## English notes: lower bound

Lower bound returns the position of the first element greater than or equal to the target in sorted input. The returned position may equal the array length. A caller checking membership must first verify that the position is in bounds, then compare the element with the target. A valid insertion position does not imply membership.

The terms binary search and 二分查找 refer to the same search technique in these notes. Lower bound is a particular search objective, not a synonym for every binary search operation.

This example distinguishes an insertion point from a successful membership test. It does not describe balancing a tree, hashing or concurrency control.
