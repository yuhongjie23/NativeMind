# NativeMind v2.0.1

本次将 11 月 9 日 v2.0.0 发布后的本地改进重新构建并同步到 Windows 安装包与 Anna Local 工具包。

## 下载与更新

- 普通 Windows 用户下载 **NativeMind_2.0.1_x64-setup.exe**。先在设置中备份数据，退出旧程序，再安装新版本；原桌面身份与默认数据目录保留。
- **nativemind-2.0.1-windows-x86_64.zip** 是 Anna Executa 专用工具包，不是普通安装包。Anna 打开独立本机窗口，使用独立数据目录；工具更新后需关闭旧窗口再打开。
- 在设置顶部确认版本号 **2.0.1**。源码下载不能代替 Windows 安装包；旧 v2.0.0 附件不覆盖。

## 背景视频

四个视频已经内置在程序资源中，不需要另找背景文件夹，也不需要额外下载。在 **设置 → 内置视频场景** 选择：日常白天、春日白天、图书馆黄昏、夏日萤火虫夜晚。

只有这四个组合使用视频；其他天气和时段仍为静态背景。“跟随本地时间”可能切换到静态组合。自定义视频优先，可用“恢复内置背景”切回；减少动态效果或专注期间会暂停视频。视频静音循环，音乐独立控制，模型与背景音乐不随安装包下载。

## 知识管理与 AI

- 标准笔记整理：预览原文与整理草稿，确认后另存副本，不覆盖原笔记。
- 知识卡片、主题目录、标题建议、分批整理进度与来源追溯。
- Wiki 链接、反向引用、改名时的链接同步；局部图谱支持一至两层关系与筛选，移除“需要复习”作为图谱关系的展示。
- 改进快速导入笔记的标题命中、中文检索、长段落重排、引用偏移与证据核验；修复模型切换与导入取消后的重试问题。
- 普通桌面的复杂 AI 知识整理只使用 DeepSeek，需配置 API Key 并主动开启授权，相关文本将发送给 DeepSeek。AI 建议仍需确认。**Anna Local 保持纯本地，禁用 DeepSeek 整理与外部搜索。**
- 面板按需加载，读取失败可重试，切换知识与复盘面板保留会话内状态。

## 验证与限制

自动化回归 1,114 项通过、4 项可选集成跳过；Rust 库 41 项、启动器 3 项测试以及类型和 ESLint 检查通过。四个视频在生产前端逐一确认加载并播放。长文档实测仍有明确限制：同一套十题中，2 道正向正确、2 道正确拒答、6 道尚未解决。引用存在不代表结论一定可靠，仍应核对原文。

本次没有用全新 Windows 电脑完成验收；Anna Agent 的真实安装/升级仍待验证。Anna 是否公开上架取决于平台审核，不因上传工具包而自动完成。Windows 安装包尚无 Authenticode 签名。

Windows x64 only. Four silent video scenes are bundled. Ollama models are installed separately. The regular desktop edition offers opt-in DeepSeek organization; Anna Local remains local-only. Back up your data and close the old app before updating.
