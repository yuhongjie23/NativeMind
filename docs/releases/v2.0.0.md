# NativeMind v2.0.0

NativeMind brings tasks, focus, documents, linked notes and AI-assisted learning review into a local-first desktop app.

## Download

- **Windows desktop:** `NativeMind_2.0.0_x64-setup.exe`. This is the normal desktop app; it retains the original application identity and default data location.
- **Anna:** the separate `nativemind-2.0.0-windows-x86_64.zip` is an Executa tool archive for Anna's local Windows Agent, not a replacement setup installer. The full app opens in a separate local window; Anna receives launch status only.
- AI requires a separately installed Ollama service and compatible models. Existing `qwen3:14b` can be used for generation; knowledge indexing uses `nomic-embed-text`. Models are not bundled or downloaded automatically.
- Background music remains an optional download from the earlier release; it is not duplicated in this installer.

## What's changed

- Four matching animated backgrounds: everyday daytime, spring daytime, library dusk and summer firefly night. Videos are silent and loop; matching still images remain available as fallbacks where supplied. Custom local background videos remain supported.
- Improved layout, English UI and language-aware companion/letter prompts.
- Recent conversation history is included in letter replies, with conversation separation and bounded context.
- Incoming letters and learning reviews use recorded learning activity; evidence checks and source excerpts reduce unsupported claims. AI output remains fallible and suggestions require confirmation.
- Resume document reading with a saved position and question; document find and evidence navigation remain available.
- Learning/reminder workflows, startup diagnostics, local backup and data handling improvements accumulated since v1.
- Anna Local: separate local app/data identity, a launch-only Executa, local confirmation, file integrity checks, disabled cloud AI/search and non-inherited platform credentials.

## Upgrade and known limits

Back up your data in Settings before upgrading. The Anna edition uses a separate data location; restore a chosen backup if you want to migrate existing desktop learning data. Close NativeMind Local before updating its Anna tool package.

This release provides Windows x64 binaries. Microsoft WebView2 is required. Windows Authenticode signing is not configured. A completely clean second-PC/VM installation test remains pending; build and local automated checks do not substitute for that test. Anna publication is subject to the platform's review and installation requirements; a GitHub release does not imply Anna approval.

Validation: 800 automated tests passed (4 optional native integration tests skipped), TypeScript and ESLint passed; Rust desktop/local-edition and launch-tool tests passed in the release preparation. The two new background videos were decoded and packaged as optimized H.264 assets. Exact release checksums are supplied alongside the downloads.
