# NativeMind 新风格探针 V2：静谧动画背景 × 数字水粉

> 用途：替代旧版“柔和扁平插画 + 纸张颗粒”风格探针。
>
> 当前只验证新画风，不生成女孩、宠物、动画和正式场景资产。

---

## 0. 为什么更换

旧提示词容易触发生成模型的通用 Cozy 模板：

- 奶油白墙面和浅木家具。
- 大面积均匀柔光和泛白滤镜。
- 轮廓明确但空间层次薄。
- 像儿童绘本、矢量插画或模板化学习房间。
- 四张候选只改变颗粒和木色，实质上仍是同一种结果。

新版改为：

```text
日系生活动画背景美术
×
哑光数字水粉
×
少量干刷与综合色边缘
×
中等偏深的成人书房色调
```

它不是人物动漫截图，也不是厚重油画。目标是“有手绘温度和空间空气，但家具结构仍然清楚”的桌面场景背景。

## 3. 推荐版风格探针提示词

这是首选版本。建议先用完全相同的提示词生成四张候选，不要让四张分别采用四种画风。

```text
为 Windows 桌面端学习辅助软件 NativeMind 生成一张书房风格探针。当前只验证画风、综合色板、边缘语言、材质概括和室内光线，不生成正式资产。

严格使用“日系生活动画背景美术 × 哑光数字水粉”的视觉语言。不是动漫人物截图，而是没有角色的生活场景背景美术。用数字水粉的大块综合色塑造墙面、书架、桌体和光影，局部加入克制的干刷与轻微画布纹理；主要依靠色块之间的明度差、冷暖差和边缘软硬建立形体，不使用统一黑色描边，不使用矢量式封闭线稿。

画面应像经过整理的动画电影背景设定稿：家具比例可信、结构线稳定，近景结构边稍清楚，中景使用综合色边缘，远景适度柔化；保留能看见的手绘笔触，但不能模糊、脏乱或像未完成概念草图。墙面、木材、玻璃和书本通过块面变化表现，不逐条绘制纹理。

采用中等偏深、低饱和但不灰暗的成人书房色板。中深胡桃木和烟熏木占 35%-45%，苔藓绿灰和炭绿灰占 25%-30%，低饱和灰青与蓝灰占 10%-15%，旧纸褐和灰褐占 8%-12%，暗金点缀小于 5%。中间明度占 55%-65%，暗部占 25%-35%，亮部只占 8%-12%，接近白色的高光小于 3%。不得出现纯白墙、奶油白主调和通体棕橙滤镜。

晴日自然光从左侧侧窗进入。窗外比室内亮，但仍能看见低饱和蓝灰天空、远处低矮屋顶或山丘和树冠，不得过曝为白色。室内保持中等偏深，通过左侧稍暖的自然光与室内背光区偏冷的绿灰综合色形成安静层次。桌面只出现一小块柔和落光，不使用白雾、奶油色泛光、强光束和全屋均匀提亮。

构图严格采用已确定的用户朝向书房骨架：16:9，48mm 标准镜头，完全平视，标准单点透视，主消失点位于 x=48%、y=43%。相机在学习桌正前方略偏左。桌子正面朝向屏幕前用户，桌面前沿与画面底边近似平行；左侧侧墙有一扇面积较小的窄高窗；后墙中央是未来女孩身后的中型书架；桌面左侧固定一盏简洁台灯。中央未来角色区、右侧 Focus HUD 区和底部 Dock 区保持低细节。

只生成固定场景：墙面、地板、左侧侧窗、窗外三层远景、后墙书架、正面书桌和一盏台灯。不要生成人物、女孩、宠物、动物、椅子、笔记本、铅笔、鱼缸、时钟、蜡烛、杯子、盆栽、海报、便签、文字、Logo、UI 和多余装饰。

最终观感：安静、有空间厚度、有手绘温度、可爱但不幼态，像一部成熟日常动画中专门为长期学习设计的室内背景。第一眼应感到这是一个面向用户的私人书房，不是展示插画、儿童房、咖啡店或游戏场景。
```

## 5. 三个渲染密度版本

三者属于同一个 Style DNA，只改变笔触密度。推荐先生成 B。

### A. 更干净的动画背景

在推荐版提示词末尾追加：

```text
渲染密度 A：结构清楚优先。减少可见笔触和干刷，色块边缘更整洁，家具结构边更稳定；仍然不能变成矢量插画或统一描边。适合 UI 覆盖和小尺寸显示。
```

### B. 平衡数字水粉，推荐

在推荐版提示词末尾追加：

```text
渲染密度 B：结构与手绘感平衡。近景桌体和书架结构清楚，墙面、阴影和窗外远景保留适量数字水粉笔触与综合色边缘。既不像矢量图，也不显得粗糙，是本轮首选。
```

### C. 更明显的手绘笔触

在推荐版提示词末尾追加：

```text
渲染密度 C：适度增加墙面、木材和阴影中的干刷与综合色笔触，但家具边缘、透视和 UI 安全区仍需清楚稳定。不要变成厚涂油画、模糊概念图或脏乱肌理。
```

不要在同一张图里要求 A、B、C 三种效果。先用 B 生成四张，再根据结果决定是否尝试 A 或 C。

## 6. 定向修正词

每次只使用一个修正块。

### 6.1 仍然太扁平

```text
只修改渲染媒介，不改变构图、家具、色板和光向。去除矢量式封闭色块和统一描边，增加数字水粉的综合色块面、边缘软硬变化、局部干刷和自然明暗转折。让墙面、木材和阴影具有手绘层次，但保持家具结构清楚。
```

### 6.2 仍然太亮或太白

```text
只调整综合色值，不改变构图和风格。将白色、奶油色和浅米色大面改为中等明度的苔藓绿灰、烟灰褐和灰青综合色；中间明度保持 55%-65%，暗部增加到 25%-35%，亮部压缩到 8%-12%，近白高光小于 3%。保留晴天窗外，但不允许窗光洗白室内。
```

### 6.3 太像照片或 3D

```text
只降低写实渲染感，不改变家具比例和透视。把照片级纹理、镜面反射、真实景深和 3D 环境光遮蔽改为数字水粉的概括色块、可见笔触和简化材质。保持真实空间比例，但画面必须明确是手绘动画背景。
```

### 6.4 太糊或像概念草图

```text
只提高结构完成度，不改变水粉媒介。加强桌沿、书架立柱、层板、窗框和台灯的稳定形状，清理脏乱笔触和随机边缘；墙面与远景仍可柔和，不能加入统一黑描边和照片锐化。
```

### 6.5 太棕或太复古

```text
只校正色彩平衡，不改变明度和材质。减少全局棕橙与黄色滤镜，在阴影、墙面和窗外加入低饱和苔藓绿灰、灰青和蓝灰综合色；胡桃木保持暖色，但不得污染整幅画面。
```

```text
第 1 步：上传已通过的书房灰阶骨架图。
第 2 步：可选上传喜欢的参考图，只声明为风格氛围参考。

第 6 步：使用同一提示词生成四张候选。
第 7 步：只评价画风，不评价后续女孩和宠物效果。
第 8 步：选中一张后再使用第 6 节的单项修正词。
```

参考强度原则：

- 骨架图：结构参考高。
- 喜欢的房间图：风格参考中等，结构参考低。
- 文本 Style DNA：高优先级。
- 不要同时上传多张职责不明的房间图。

## 8. 验收标准

100 分制，低于 85 分不冻结：

| 项目 | 分值 | 判断 |
| --- | ---: | --- |
| 媒介辨识 | 20 | 明确是动画背景式数字水粉，不是矢量、照片或 3D |
| 空间厚度 | 15 | 前中后景和家具体积成立，不依赖粗描边 |
| 色值结构 | 15 | 中间明度为主，亮部受控，没有奶油白统治 |
| 色彩关系 | 15 | 胡桃木、绿灰、灰青和旧纸褐平衡，不通体棕橙 |
| 成人可用 | 15 | 安静、成熟，不像儿童绘本和游戏房间 |
| UI 兼容 | 10 | 右侧和底部低细节，前景不抢 HUD |
| 长期观看 | 10 | 笔触有温度但不躁动，明暗不过分刺激 |

一票否决：

- 仍然像旧版奶油白扁平 Cozy 插画。
- 必须依靠粗轮廓才能分辨家具。
- 窗户重新成为画面中心或主消失点。
- 出现人物、宠物、椅子和桌面接触道具。
- 右侧 HUD 区被高对比书架或窗框占据。
- 画面过暗到书架和桌体无法辨认。
