# NativeMind v2.0.2

本次重点修复笔记更新后搜索仍使用旧内容的问题，并在 AI 回答展示前检查资料是否仍有效。

## 新增与优化

- 尚未完成向量索引的笔记支持关键词兜底搜索；完整标题查找不再受旧候选数量上限影响。
- 同一篇长文档按笔记去重展示，不同的同名笔记仍保留。
- 保存笔记内容后旧派生索引失效；解析、切片和嵌入任务检查内容版本，拒绝过期写入。
- AI 生成与核验阶段检查来源；资料变化或无法验证时撤下草稿和引用，不把失败结果写入问答历史。历史答案不自动重写。
- 保留四个内置视频场景、自定义视频、笔记整理、Wiki 链接与图谱导航等 v2 能力。

## 下载与升级

普通 Windows 用户下载 `NativeMind_2.0.2_x64-setup.exe`。`nativemind-2.0.2-windows-x86_64.zip` 是 Anna 专用本机工具包。`SHA256SUMS.txt` 可用于校验下载文件。

升级前在设置中备份数据，退出旧版后安装；设置中应显示 2.0.2。首次启动自动升级本地数据库，清理明确失效的派生索引。背景视频与图片已内置，音乐包另在 [资源存档](https://github.com/yuhongjie23/NativeMind/releases/tag/v0.1.0) 下载，原资源地址保留。

## 验证与限制

- 1164 项自动化测试通过、4 项可选跳过；另有 2 项原生集成和 3 项启动器测试通过。
- 上传文件 SHA-256 已与本地核对一致。
- 来源有效性检查不等于答案正确性保证。真实长 PDF/EPUB 十题验收仍有 6 题未解决，2 题正向正确、2 题正确拒答。
- Anna 新版已提交审核，截至 2026-11-11 尚未正式上架；全新 Windows 电脑与 Anna Agent 安装升级仍待实机验收。
