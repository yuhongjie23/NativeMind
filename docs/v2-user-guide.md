# NativeMind v2 使用与自测指南

适用版本：**v2.0.2**，更新日期：2026-11-11。

NativeMind 把学习任务、专注、资料阅读、笔记关联和复盘放在一个本地工作空间。AI 用于生成可检查的建议；知识整理和任务建议需你确认后保存。

## 安装与升级

1. 从 [最新发布](https://github.com/yuhongjie23/NativeMind/releases/latest) 下载 `NativeMind_2.0.2_x64-setup.exe`，这是普通 Windows 桌面安装包。
2. 已有数据时，先在设置中导出备份，退出旧程序再安装。首次启动会升级本地数据库。
3. 打开设置，确认版本显示 `2.0.2`。笔记与任务可以先使用，AI 模型需要单独安装和配置。

`nativemind-2.0.2-windows-x86_64.zip` 是 Anna 专用工具包，不是普通桌面安装包。Anna 版由平台启动本机独立窗口，使用独立数据目录；截至上述日期，新版仍待平台审核，全新电脑和 Anna Agent 安装升级尚未完成实机验收。

## 从资料到知识库

在知识面板导入 PDF、EPUB、Markdown、文本，或粘贴笔记。导入后可以阅读、编辑、搜索和建立关联。

- **找一篇笔记**：先试完整标题或标题片段。v2.0.2 修复了较早笔记漏检与长文档重复展示。
- **找一段内容**：输入正文关键词。尚未完成向量索引的笔记也有关键词兜底，但同义表达和语义搜索需要索引及模型支持。
- **改过笔记后再搜索**：旧切片会失效，后台旧任务不能覆盖新内容。语义结果需等待新索引完成；不应再把旧内容当作当前证据。
- **在文档里定位**：使用 Ctrl+F 查找，按界面提供的上一个/下一个匹配跳转；问答中也可以点击引用查看资料上下文。

搜索没有结果不一定表示资料不存在：先核对标题、正文是否成功导入，再检查索引状态和向量模型。不要只凭一次语义搜索删除或重复导入资料。

## AI 整理与知识图谱

普通桌面版的 AI 知识整理需要 DeepSeek API Key，并在设置中单独启用。发起整理前阅读界面的数据发送范围：此功能会把所选内容发送给 DeepSeek，不属于纯离线处理。

可用能力包括标准笔记整理、知识卡片、主题目录与关联建议。先查看草稿是否保留原意、标题是否易懂、关联是否有依据，再确认保存。Wiki 链接、反向引用和局部图谱帮助从当前笔记找到相关资料；图谱中的连线不是知识掌握程度评分。

Anna Local 禁用云端知识整理，仍可使用手动笔记、关联和图谱导航。没有 Key 不影响这些本地能力。

## 用自己的资料提问

输入问题后，查看检索与生成进度；长请求可以取消。拿到答案后，优先检查引用是否支持对应结论。

v2.0.2 新增来源有效性保护：如果回答生成期间笔记被编辑、删除或重新切片，旧草稿和引用会被撤下，提示重新提问。来源无法验证时也不保存这次失败结果。以前保存的问答历史不会自动重写，应重新提问以获取最新内容。

这一保护防止使用失效来源，**不保证模型不会误解资料**。当前真实长 PDF/EPUB 十题验收仍有 6 题未解决，另外 2 题正向正确、2 题正确拒答。复杂跨章节问题、长文档召回与核验超时仍需改进；不要把自动化测试通过等同于所有知识问答都准确。

## 学习计划、专注与复盘

- 任务：自行添加，或让 AI 拆成草稿，选择采用后加入计划。
- 专注：关联任务、计时，按需播放环境音或本地音乐；陪伴功能在专注时减少打扰。
- 提醒：设置一次、每日或每周学习/复习计划；到期后完成、延后、跳过或停止。错过的事项保留供处理。
- 复盘：结合任务、专注和自评记录查看学习情况，确认后保存 AI 建议。自评历史记录困难点，不代表自动测验分数。
- 系统通知：Windows 退出应用后的提醒需安装身份及通知权限；关机、勿扰或系统限制可能阻止送达。
- 书信与陪伴：按需互动，查看结合学习记录的来信；建议不应被视为自动创建的任务。

## 背景与音乐

安装包已内置四个视频场景：日常白天、春日白天、图书馆黄昏、夏日萤火虫夜晚。在设置的“内置视频场景”切换；其他场景仍可能使用静态图。

视频嵌在应用资源中，安装目录没有独立视频文件夹也属正常。自定义本地视频优先；减少动态效果或进入专注时会暂停背景视频。视频静音循环，音乐单独控制。

背景音乐另从 [资源存档](https://github.com/yuhongjie23/NativeMind/releases/tag/v0.1.0) 获取 `nativemind-background-music.zip`，按设置中的资源目录配置。没有音乐包不影响笔记、学习计划或 AI 功能。

## 本地模型与联网范围

在设置中检查 Ollama 服务和已安装模型。当前默认生成模型为 Qwen3 4B / 14B，向量模型为 `nomic-embed-text`。14B 对内存和显存要求较高，应按设备条件选择，模型下载和运行资源不包含在安装包中。

普通桌面版可以主动启用 DeepSeek；相关请求内容会发送至该服务。外部搜索也是可选联网功能。Anna Local 仅使用本地模型，Anna 接收启动请求和固定状态，不接收笔记或对话内容。详见 [隐私说明](PRIVACY.md)。

## 五分钟检查新版是否生效

用临时笔记测试，避免改动重要资料：

1. 新建标题为“检索验收笔记”的笔记，写入一句独特内容，如“实验编号 ZK742，温度为 27 度”。
2. 搜索完整标题和 `ZK742`，检查能否找到该笔记，同一笔记是否重复出现。
3. 把温度改成 31 度并保存，再查正文，确认不把旧数值作为当前结果。等待索引完成后，再用资料问答询问温度。
4. 点击答案引用，核对是否指向这篇笔记、原文是否确实支持结论。若资料不足或核验失败，应重新检查资料，不能视为通过。
5. 切换四个视频场景，检查视频、静音和暂停行为；关闭重开应用，确认笔记仍在。

这套检查验证基本体验，不能替代长文档、多模型和全新电脑测试。发布前记录为 1164 项自动化测试通过、4 项可选跳过，另有 2 项原生集成和 3 项启动器测试通过。
