# NativeMind 即梦书房用户朝向骨架图提示词 V1

> 目标：先生成一张只验证空间、透视、家具位置和 UI 安全区的书房骨架图。
>
> 本阶段不是正式插画，不生成女孩、宠物、椅子、笔记本、铅笔、装饰动画或真实 UI。

---

## 0. 最终构图结论

这是一个面向屏幕前用户的第三方平视书房：

- 相机位于学习桌正前方略偏左。
- 主光轴和单点透视消失点都落在中央学习区，不落在窗户上。
- 桌子正面朝向用户，桌子前沿与画面底边近似平行。
- 窗户位于左侧侧墙，只负责自然光和天气展示。
- 书架位于后墙中央，是未来女孩身后的背景结构。
- 台灯固定在桌面左侧，不占女孩和未来宠物动作区。
- 右侧保持低细节，供 Focus HUD 使用。
- 底部保持无关键对象，供 Dock 和音乐条使用。

屏幕前用户是观察者，但不是第一人称 POV。画面中不出现用户的手、手臂、膝盖、键盘边缘或镜头前身体。

## 1. 先修正原始透视描述

标准单点透视中，并不是所有线都指向消失点：

```text
指向消失点：
- 桌面左右两侧向房间深处延伸的线
- 左侧墙面向后延伸的踢脚线和顶线
- 侧墙窗户的上沿、下沿和窗台纵深线
- 地板或地毯朝房间深处的纵向线

保持水平：
- 桌子正面边缘
- 后墙书架的水平层板
- 后墙与画面平行的水平结构

保持垂直：
- 书架立柱
- 墙角竖线
- 台灯主杆
- 窗框竖直边
```

如果让桌子正面边缘也斜向窗户，模型会再次生成“人物和空间面向窗户”的构图。

## 2. 骨架阶段的素材边界

### 2.1 必须出现

- 后墙和左侧侧墙。
- 左侧侧墙的一扇窄高窗。
- 后墙中央的中型书架。
- 正面横向书桌的桌面和桌身。
- 桌面左侧的一盏简化台灯。
- 窗外三层极简风景：天空、远处低矮屋顶或山丘、树冠。
- 右侧低细节墙面。
- 地板和简单踢脚线。

### 2.2 必须移除

- 女孩和任何人物。
- 宠物和任何动物。
- 椅子。
- 笔记本、铅笔、书写纸和手部接触道具。
- 鱼缸、时钟、蜡烛、茶壶、咖啡杯、盆栽和装饰花瓶。
- 可读书名、海报、便签和文字。
- Focus HUD、Dock、音乐条和任何伪 UI。
- 阳光粒子、飞鸟、雨雪和动画特效。

椅子跟随未来女孩角色包，笔记本和铅笔跟随女孩的手部动画；它们不应被烘焙进背景。

## 4. 空间关系细则

### 4.1 桌子

- 桌子是画面主要水平稳定线。
- 正面边缘必须近似水平，不朝左窗或右侧 HUD 倾斜。
- 桌面只表现足够判断深度的上表面，不做夸张俯视。
- 桌子中部为空，给未来女孩的前臂、笔记本和书写动作使用。
- 桌体可以延伸到画面底部，但底部 Dock 区不能出现抽屉把手、桌腿或高对比木纹等关键细节。

### 4.2 后墙书架

- 书架位于未来女孩正后方，形成明确的“书房”身份。
- 书架整体宽度约为画面 43%，不铺满整面墙。
- 书架前表面与后墙平行，层板保持水平，立柱保持垂直。
- 中央 `bookshelf_quiet_center` 区域减少书本密度和明暗跳变，避免未来女孩的头发、脸和肩膀与书脊混在一起。
- 骨架阶段只画层板和少量矩形书块，不画书名、装饰品和复杂书脊。

### 4.3 侧窗

- 窗户必须位于左侧侧墙，不位于人物正后方。
- 窗户面积约占全画面 8%，不能成为大面积落地窗。
- 窗户使用左侧墙面的透视，窗台和上下沿向中央消失点轻微收敛，竖边保持垂直。
- 窗户只提供侧向自然光和天气展示，不承担画面的纵深出口。
- 窗外风景限制在玻璃内部，只有三层大形状，不画城市霓虹和复杂建筑。

### 4.4 台灯

- 台灯固定在桌面左侧，位于窗户下方偏右，但不与窗框连接。
- 使用灯罩、灯杆和底座三个简单块面即可。
- 骨架阶段不画光晕、灯泡、反射和材质。
- 台灯不能进入未来女孩的手部区，也不能覆盖书架中央安静区。

### 4.5 未来角色空间

- 骨架图中不画女孩、宠物、椅子和任何占位人形。
- 通过空桌面、书架中央低细节区和家具间距保留角色空间。
- 未来女孩身体正面朝向用户，只允许偏转 15-20 度形成近正面三分之四视角。
- 未来宠物仍使用项目锚点 `[0.70, 0.62]`，因此台灯和固定道具不能放在该位置。

## 5. 灰阶骨架视觉语言

骨架图只使用 5 个明度层级：

```yaml
value_0_lightest: "窗外天空和安全区检查底色"
value_1_light: "后墙和远景"
value_2_mid: "书架框架、桌面和地板"
value_3_dark: "桌身、窗框、台灯"
value_4_guide: "极细透视辅助线，仅审核版使用"
```

要求：

- 使用纯色几何块和非常轻的轮廓。
- 无最终木纹、纸张颗粒、布料、玻璃反光和笔触。
- 无真实光影，只保留左侧窗户较亮、室内中间明度的基本关系。
- 无文字标签。即梦生成文字不可靠，坐标和对象名称保留在本文档中。
- 无景深、模糊、发光、体积光和装饰效果。

## 9. 参考图使用方式

如果上传用户喜欢的现有房间图，先附加以下责任声明：

```text
参考图只负责：
- 安静、横向展开的空间节奏。
- 前景桌面、中景学习区、后景家具的分层感。
- 柔和、成人可用、长期观看不过度兴奋的氛围。

参考图不能决定：
- 原来的相机位置和主消失点。
- 原来的窗口尺寸和位置。
- 原来人物、宠物和桌面物件。
- 原来的高亮、泛白曝光和最终色板。
- 原来的 UI、巨型悬浮笔记本和装饰内容。

当参考图与本文坐标冲突时，以本文的相机、透视、对象框和安全区为最高优先级。
```

即梦参数名称可能随版本变化，原则如下：

- 原图作为风格或空间节奏参考：低到中等强度。
- 本文坐标和文本构图：最高优先级。
- 不要把错误视角的原图设为高结构继承。
- 每次只生成一种骨架，不同时要求正式配色和角色。
